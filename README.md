# 迷因幣雷達 V3.1

Solana 迷因幣自動掃描與模擬交易系統。

## 啟動

```bash
python server.py
```

## V3.1 核心改進

1. **背景自主掃描** — 伺服器啟動後每 15 秒獨立執行，前端只讀取結果
2. **mint address 管理** — 持倉、冷卻、黑名單全部以 address 對應
3. **Jupiter 可成交報價** — 進出場以實際報價為準，價格衝擊 >2% 不進
4. **執行鎖** — 避免重複下單

## 交易規則

| 項目 | 設定 |
|---|---|
| 本金 | $1,000 |
| 每筆 | $75 |
| 最大持倉 | 3 |
| score | >= 5 |
| 流動性 | >= $75,000 |
| 買盤 | >= 55% |
| 停損 | -12% |
| 鎖利 | peak>=50% 且 pnl<20% 出場 |
| 移動停利 | peak>=30%，回撤 20 百分點 |
| 未延續 | 45 分鐘 pnl<3% |
| 最長持有 | 2 小時 |
| 價格衝擊 | >2% 不進場 |
| 虧損冷卻 | 同 mint 當日不進 |
| 下架 | 8 次查無報價（5 分鐘寬限） |

## API

- `GET /api/dex` — 讀取最新狀態
- `POST /api/clear_sim` — 重置模擬帳戶
