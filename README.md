# 迷因幣雷達 V3.2

Solana 迷因幣自動掃描與模擬交易系統。

## 啟動

`bash
python server.py
`

## 入場流程（6 關）

1. 分級門檻：流動性>=$75K 需 score>=5、買盤>=52%、衝擊<=2%；$35-75K 需 score>=5、買盤>=52%、衝擊<=1.5%
2. 幣齡：3 分鐘～24 小時
3. 兩階段確認：連續 2 次掃描通過
4. 觸發：突破前高 或 回踩 10-25% 站回均價
5. Jupiter 報價衝擊確認
6. 部位大小 = min($75, 流動性x0.15%)

## 出場

- 停損 -12%
- peak >= 15% 啟動移動停利，回撤 10pp 出
- peak >= 50% 且 pnl < 20% 鎖利
- 45 分鐘 pnl < +3% 出
- 最長持有 2 小時
- rug/下架/流動性流失 -> 永久黑名單
- 其他出場 -> 24 小時冷卻

## 熔斷

- 連敗 5 次 -> 停 1 小時
- 日虧 $150 -> 停當日
