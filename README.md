# 迷因幣雷達 V3.1

Solana 迷因幣自動掃描與模擬交易系統。

## 啟動

```bash
python server.py
```

## 核心架構

1. **背景自主掃描** — 每 15 秒獨立執行，前端只讀取結果
2. **mint address 管理** — 持倉、冷卻、首次觀察皆以 address 為鍵
3. **Jupiter 報價** — 買入前查衝擊，decimals 由 Solana RPC 取得
4. **執行鎖** — 避免重複下單

## 交易規則

| 項目 | 設定 |
|---|---|
| 本金 | $1,000 |
| 每筆 | $75 |
| 最大持倉 | 3 |
| 流動性 ≥ $75K | score≥5、買盤≥52%、衝擊≤2% |
| 流動性 $35–75K | score≥6、買盤≥55%、衝擊≤1.5% |
| 流動性 < $35K | 不交易 |
| 停損 | -12% |
| 鎖利 | peak≥50% 且 pnl<20% |
| 移動停利 | peak≥30%，回撤 20 百分點 |
| 未延續 | 45 分鐘 pnl<3% |
| 最長持有 | 2 小時 |
| 冷卻 | 同 mint 當日不進（任何出場後） |
| 觀察期 | 首次出現後 15 分鐘 |
| 下架 | 連續 8 次查無報價（5 分鐘寬限） |

## API

- `GET /api/dex` — 讀取最新狀態
- `POST /api/sell/<address>` — 手動賣出
- `POST /api/clear_sim` — 重置模擬帳戶
