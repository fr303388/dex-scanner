# 迷因幣雷達 (dex_scanner) — V3 模式

Solana 迷因幣自動掃描與模擬交易系統。

## 啟動方式

```bash
python server.py
```

瀏覽器開啟 http://127.0.0.1:8770/

## 交易哲學

精選不亂買。嚴格過濾流動性與買盤，虧損快砍、獲利先落袋一半，弱勢幣長時間冷卻不重複踩。

## 當前交易規則

| 項目 | 設定 |
|---|---|
| 本金 | $1,000 |
| 每筆投入 | $75 |
| 最大持倉 | 5 |
| 買入門檻 | score >= 5 |
| 最低流動性 | >= $75,000 |
| 買盤比例 | >= 55% |
| 停損 | -12% |
| 半獲利 | +50% 賣一半 |
| 鎖利出場 | peak >= 50% 且 pnl < 20% |
| 移動停利 | peak >= 30%，回撤 20 個百分點出場 |
| 未延續出場 | 45 分鐘且 pnl < 3% |
| 流動性異常 | 較入場下降 40% 出場 |
| 最長持有 | 2 小時 |
| 虧損冷卻 | 6 小時（以 token address） |
| 下架判定 | 連續 8 次查無價格 |

## 評分規則

- +2 1h 漲 10-30% · -1 1h 漲 >30%（追高風險）
- +2 24h 漲 10-50% · +1 50-150% · -1 >200%
- +1.5 交易量 >$200K · +0.5 >$50K
- +1.5 流動性 >$50K · +1 >$30K · -2 <$10K · -3 <$5K
- +1.5 買盤 >70% · -1.5 買盤 <40%
- +3 買家 <10 人（刷單）· -1 <30 人
- -2 量/流動 >5 · -3 1h>80% 且 24h>300%
- -3 交易 <30 筆 · -1 <80 筆
- -5 GMGN 洗盤偵測
- +2 GMGN 聰明錢 >=5 人 · +1 >=2 人

## 帳本保護

- 壞損的帳本自動備份為 `.corrupt-時間戳`，再建立新樣本
- 已移除價格強制限制，避免低估 rug 風險

## API

- `GET /api/dex` — 所有資料
- `POST /api/clear_delisted` — 清除下架列表
