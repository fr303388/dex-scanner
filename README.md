# 迷因幣雷達 (dex_scanner) — V2 模式

Solana 迷因幣自動掃描與模擬交易系統。

## 啟動方式

```bash
python server.py
```

瀏覽器開啟 http://127.0.0.1:8770/

## 交易哲學

不追已經漲上去的幣。買進新幣、買盤強的、流動性剛建立的。-15% 快砍不留屍體，peak +30% 就開始保護獲利。

## 當前交易規則

| 項目 | 設定 |
|---|---|
| 本金 | $1,000 |
| 每筆投入 | $75 |
| 最大持倉 | 8 |
| 買入門檻 | score >= 4 |
| 最低流動性 | > $30,000 |
| 上線時間 | > 15 分鐘才買 |
| 買盤比例 | >= 40% |
| 1h 漲幅 | > 30% 扣分（不追高） |
| 停損 | -15% |
| 移動停利 | peak >= +30% 啟動，從峰回吐 30% 賣 |
| 虧損後冷卻 | 0 分鐘 |
| 死幣不動 | 30 分鐘且虧損才賣 |
| 最長持有 | 4 小時 |
| 下架判定 | 連續 8 次查無價格 |

## 評分規則

- +2 1h 漲 10-30% · -1 1h 漲 >30%（追高風險）
- +2 24h 漲 10-50% · +1 50-150% · -1 >200%
- +1.5 交易量 >$200K · +0.5 >$50K
- +1.5 流動性 >$50K · +1 >$30K · -2 <$10K · -3 <$5K
- +1.5 買盤 >70% · -1.5 買盤 <40%
- +3 買家 <10 人（刷單）· -1 <30 人
- -2 量/流動 >5 · -3 1h>80% 且 24h>300%
- -3 交易 <30 筆 · -1 <80 筆
- -5 GMGN 洗盤偵測
- +2 GMGN 聰明錢 >=5 人 · +1 >=2 人
